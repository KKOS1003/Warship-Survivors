# 敌舰 JSON 配置说明（V12）

六个文件分别对应巡逻艇、驱逐舰、巡洋舰、精英巡洋舰、战列舰和 Boss，可独立导入、导出或恢复默认。敌我使用相同的 `schemaVersion: 1` 基础格式。敌方另有 `enemy` 专用 AI 和奖励参数。

## 关键字段

| 字段 | 作用 |
|---|---|
| `stats.maxHp` | 舰体基础耐久 |
| `stats.maxKnots` / `stats.acceleration` | 最大航速 / 加速度 |
| `stats.armor` / `stats.regen` | 伤害减免比例 / 每秒被动恢复 |
| `model.lengthMeters`、`model.collision` | 模型尺寸、命中与舰体碰撞盒 |
| `weapons.main.damage/range/reload/turnRate/spread` | 主炮单发伤害、射程、单炮塔装填、旋回速度和散布 |
| `weapons.main.turrets[]` | 每座主炮的位置、射界、朝向、独立炮管数量 |
| `weapons.main.turrets[].barrels` | 决定该炮塔每次齐射发数；1 为单管炮 |
| `weapons.main.turrets[].origin` | 本地炮口坐标 `[x,y,z]`（米） |
| `weapons.secondary.initialCount` | 有效副炮数，需不超过 mounts 长度 |
| `weapons.secondary.mounts[]` | 每门副炮的左右舷 side 和坐标 x/y/z |
| `weapons.antiAir.damage/accuracy/rate/range` | 防空伤害、命中率、射速、射程 |
| `enemy.spawnSpeedMin/Max` | 出生时随机航速范围（不超过最大航速） |
| `enemy.turnRate` | AI 舵角旋转速度（°/s） |
| `enemy.shellSpeed` | 敌舰炮弹初速（游戏模拟米/s） |
| `enemy.reloadJitter` | 主炮装填波动比例，例如 0.12 表示 ±12% |
| `enemy.rewardXP/rewardScrap` | 击沉后奖励 |
| `enemy.boss` | 是否使用 Boss 标记、预警等 |

## 配置案例

巡逻艇：`turrets` 只有一个条目，`barrels: 1`，`secondary.initialCount: 0`。战列舰有三座炮塔，每座 `barrels: 2`；默认 Boss 三座炮塔，每座 `barrels: 3`。

导入流程：游戏设置 → **敌军舰艇库** → 先选舰种 → 选择对应 JSON（可选同时提供专属 GLB / ZIP）→ 导入。每种配置互不覆盖。战斗中导入也可以，现有已生成舰保留旧值，随后生成的新舰使用修改后的配置。

修改炮塔坐标前请核对 GLB 的本地坐标及模型 `yawOffsetDegrees`；暂不自动扫描识别模型炮塔骨架。

## V16 前 3 分钟渐进难度

各舰种 `enemy` 中新增两个可选字段，旧版 JSON 未填写时默认使用 1.0，不影响自定义配置：

- `openingDamageMultiplier`：开局第 0 秒敌舰主副炮伤害倍率，随时间线性回升，第 180 秒恢复为 1.0。例如 `0.76` 表示开局伤害为正常值的 76%。
- `openingReloadMultiplier`：开局第 0 秒敌舰主副炮装填倍率，随时间线性回落，第 180 秒恢复为 1.0。例如 `1.23` 表示开局装填时间延长 23%。

游戏另在前 3 分钟使用较小的普通敌舰编队、更长的增援间隔和较慢的常规敌机生成速度。首次 3 分钟轰炸潮仍会按规则触发。
