# V26.1 404 缺失资源修复说明

## 故障原因
V26 补丁没有包含 V25 原本的 `assets/ui_cursor.svg`、`assets/target_cursor.svg`、`assets/ocean_visual_fx.js`。网页仍引用它们，若服务器上这些文件被遗漏或目录发生变化，就会报 404。

## 安装位置（重要）
把 ZIP **内部文件**直接解压覆盖到 V25/V26 的游戏根目录（即同时放有 `index.html`、`index-online.html`、`index-local.html`、`serve.py` 的目录）。必须形成：

```
游戏目录/
  index.html
  index-online.html
  index-local.html
  serve.py
  assets/
    ui_cursor.svg
    target_cursor.svg
    ocean_visual_fx.js
    underwater_visual_fx.js
    ...（保留旧版模型文件）
  ships/   （保留）
  vendor/  （如果已安装，保留）
```

**不能**把补丁作为一个嵌套子文件夹存放在游戏根目录里；也不要删除旧 `assets/`。本包不含模型和贴图。若 V25/V26 游戏已经正常运行，只需复制这三个 `assets` 文件即可。

## 启动与核验
在游戏目录执行：

```
python serve.py --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000/ 。在浏览器直接访问下面三个地址，应该能看到文件内容而不是 `404`：

- http://127.0.0.1:8000/assets/ui_cursor.svg
- http://127.0.0.1:8000/assets/target_cursor.svg
- http://127.0.0.1:8000/assets/ocean_visual_fx.js

`ocean_visual_fx.js` 的响应头应为 `Content-Type: text/javascript`。如果仍返回 404，通常是启动服务器时指向了错误的游戏目录，或解压后多了一层文件夹。浏览器可能保留旧缓存，可强制刷新 Ctrl+F5。

服务器端的第三方引擎 `vendor/` 是另一套依赖资源，本补丁不包含引擎源码。如果启动器提示 `vendor` 缺失，执行 `python serve.py --install`（或按旧说明预装官方依赖）。

## 与 V26 的关系
本包是 **V26 原补丁加上遗漏的 V25 静态资源**，不更改战斗代码和模型，保留水下效果与 MIME 修复。全部复制覆盖即可，无需先单独安装 V26。
