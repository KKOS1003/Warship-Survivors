《战舰，最后的防线》V21 — 光学炮瞄、舰体穿透与自动维修优化

版本定位：在 V20 资源分离版上升级。index.html 不内嵌 3D 模型；assets/ 与 ships/ 应与 index.html 保持原目录。

1. 光学炮瞄弱点与水线下弹道
- Shift 进入主炮光学瞄准，自动主炮停火；单击左键逐炮开火，双击齐射。
- 手动主炮基础伤害继续 ×2，自动主炮及副炮不会触发核心区、弹药库额外倍率。
- 核心区（×4.5）和弹药库（×7）仍从 ships/enemies/*.json 的 model.criticalZones 读取。
- 手动炮弹撞击敌舰外壳后，向舰内最多穿透 88 米的射线进行弱点区域检测。
- 手动炮弹触水后，不再立即销毁：会沿前进方向在浅水下继续约 105 米作连续舰体碰撞判定；触水本身不等于命中。
- 核心区、弹药库成功命中时，镜内出现醒目的命中标识，左上角荣誉勋章计数增加，并在左侧战况日志留下记录。
- 受斜击角度约束，过大的偏斜角仍不能触发核心区额外伤害；未命中舰体或贯穿弱点仍可能落空。

2. 自动应急维修
- 默认触发阈值由 35% 调整为 30%，可在游戏设置里调整，最低 15%，最高 60%。
- 在耐久持续低于阈值、补给足够、技能可用时，根据剩余耐久缺口和当前恢复速度继续叠加 R 技能；若血量仍低于阈值且当前修复速率已足够，每隔约 3.2 秒仍允许再次触发。
- 自动维修仍遵守 R 技能冷却，自动触发之间额外设置最短 1.15 秒间隔，最多同时累积六层，避免失控消耗。
- HP 达到阈值后不再自动添加新层；已有修复会继续逐渐恢复剩余血量。

3. 升级与光学瞄准
- 进入三选一时暂时释放鼠标锁定以操作升级菜单，但保留光学瞄准模式和准星朝向。
- 选择升级后自动恢复炮瞄和鼠标锁定（若浏览器允许）。

4. 精准手动射击
- 手动炮弹散布系数调整为自动主炮的 16%，上限 30 米；散布仍随距离与火控异常等因素变化。
- 普通自动主炮的散布和装填未修改。

5. 准星停留吸附
- 镜中鼠标移动时自由瞄准；停止移动约 0.22 秒、准星碰到敌舰时，记录当时命中点在该敌舰模型上的局部坐标。
- 被锁定的瞄点随敌舰转向/移动而保持在相同舰体部位，而不是重新锁定舰体中心。
- 鼠标再次移动立即解除吸附并可调整新瞄点，停下后可重新锁定。
- 当前实现的是光学追踪（不是弹道提前量修正），移动目标仍须考虑炮弹飞行时间。

检查范围：所有内联 JavaScript 通过 node --check；局部空间弱点交会、自动维修叠加/停止以及主要状态路径进行独立测试；打包后检查 ZIP CRC。
限制：当前测试环境的浏览器阻止访问本地文件，因此没有完成三维实时试玩。请通过本地 HTTP 服务运行并确认射击轨迹、海面碰撞与鼠标锁定手感。

启动：
1) 解压后进入包含 index.html 的文件夹。
2) 运行 python -m http.server 8000
3) 用 Chrome 或 Edge 打开 http://localhost:8000/
4) 首次运行联网加载 Three.js/Open Water 依赖。
