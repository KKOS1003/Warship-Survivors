# 战舰，最后的防线 V22 · 自动锁定 / 手机横屏 / 无 jsDelivr 方案

## 推荐启动方式（不使用 jsDelivr）

1. 解压全部资源，进入包含 index.html 的目录。
2. `python -m http.server 8000`
3. 打开 `http://localhost:8000/index.html`。

新版在线模式：Three.js 从 `unpkg.com` 加载；Open Water 从 `leonxlnx.github.io` 加载。两者仍需联网，但**不使用 jsDelivr**。如果这些域名也无法访问，请使用下面的本地依赖方案。

## 将第三方引擎下载到本地（之后可离线运行）

首次在可以连接 npm 官方仓库/GitHub 的网络下执行：

```sh
python install_dependencies.py
python -m http.server 8000
```

打开 `http://localhost:8000/index-local.html`。本地版从 `vendor/three` 和 `vendor/open-water` 加载，**运行过程中不需要访问 CDN**。

安装脚本固定 Three.js 版本 0.169.0、Open Water GitHub main 分支。生产环境建议将 Open Water 固定到审定的 commit。

如果 npm/GitHub 也无法访问，可在别处下载官方归档并复制到电脑：
- npm Three.js 归档：`https://registry.npmjs.org/three/-/three-0.169.0.tgz`
- Open Water 源码：`https://github.com/Leonxlnx/open-water/archive/refs/heads/main.zip`

然后执行：

```sh
python install_dependencies.py --three-tgz three-0.169.0.tgz --ocean-zip open-water-main.zip
```

注意：本 ZIP **不直接包含第三方引擎的 JS 源码**（因当前构建环境无法从这些网站下载），因此在运行安装脚本前，`index-local.html` 不能使用。游戏舰船、飞机、模型仍已在 `assets/` 中完整打包。

## PC 操控
- Shift：进入/退出主炮瞄准；镜内 X：手动取消/选择最近方向的敌舰；目标自动锁定无需准星贴住舰体。
- 锁定追踪的是**敌舰方向**，保留玩家瞄点的相对提前量，不替玩家校正炮弹飞行时间。
- 瞄准模式**WASD 始终操控战舰**，即使之前处于自由相机模式。
- 镜内鼠标移动：调整提前量；停下后随锁定敌舰运动。单击：逐炮射击，双击：齐射。
- 常规模式左键点击海面：设航点；Ctrl+左键：追加航点；右键拖动：转相机。

## 手机/平板（横屏）
- 横屏使用；海面**轻点**设航点，**拖动**旋转镜头（不会误设航线）。
- 左下角触摸 W/A/S/D 控制战舰；右上角切炮瞄、锁定、切视角、暂停。
- 右下角提供炮瞄缩放、逐炮开火、齐射与 Q/R/T/E 四个技能键。
- 炮瞄时直接在海面拖动以改变方向，不需要鼠标指针锁定。
- 由于移动端 WebGL2 GPU 性能差异很大，建议优先使用省性能画质并降低飞机数量。

## 实现原理 / 限制
- 目标锁定参考《战舰世界》的 X 锁定最近准星目标与“镜头跟踪锁定目标”的思路，实现为角度邻近候选 + 当前目标优先 + 跟踪时保留视角偏移。并非复刻专有程序。
- 浏览器 Pointer Lock API 在部分手机上不可用，触摸版本不调用 Pointer Lock。
- 浏览器是否支持 WebGL2 / EXT_color_buffer_float 及浏览器 GPU 上限仍会影响海面引擎。
- 本次通过 JavaScript 语法和静态界面检查，不代表已完成实际三维/全程战斗验证。
