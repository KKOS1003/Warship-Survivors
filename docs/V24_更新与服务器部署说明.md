# 《战舰，最后的防线》V24

## 新功能
- **手动 / 辅助落点**：在 Shift 炮瞄模式中按 M 切换。辅助模式针对锁定目标，结合目标当前航向速度和模拟抛射飞行时间预测落点。**并非必中**：转炮、装填、弹药散布、敌舰机动、弹道和装甲斜击均保留。没有目标锁定时退回手动准星落点。
- **目标锁定**：X 锁定/解锁，Z 切换下一目标（降低了自动换目标角度阈值，但加了切换间隔避免抖动）；锁定舰艇上方有浅绿色菱形标记；移动端有切换、辅助落点按钮。
- **集火**：F 将当前炮瞄锁定舰艇设置为全舰集火目标；无炮瞄目标时进入点选集火。V 仍可手动点选，C 取消。
- **敌舰血条**：删除漂浮血条周围的黑色卡片及大边框，只保留文字、细生命条与黄色伤害残影。
- **核心区**：实际核心区判定单轴判定尺寸缩小约 5%，弹药库约 3%，高偏角触发限制由 68° 改为 66°。

## 服务器与客户端依赖
**`install_dependencies.py` 是服务器或部署电脑运行的安装脚本，不是客户端浏览器安装器。**它会将 Three.js 0.169.0 与 Open Water 官方源码放入服务器的 `vendor/` 目录，部署时执行一次即可。客户端不会运行 Python。

使用：

```bash
python serve.py --install --host 0.0.0.0 --port 8000
```

已有依赖则使用：

```bash
python serve.py --host 0.0.0.0 --port 8000
```

浏览器访问服务器 `http://服务器IP:8000/`。`index.html` 是启动器，检测在线 unpkg 与 Open Water GitHub Pages；若不能访问且服务器 `vendor/` 已安装，则切换 `index-local.html`。也可明确进入 `index-local.html` / `index-online.html`。

**如果两类源都不可用，服务器必须由管理员预先部署依赖。浏览器不能直接执行安装脚本，也不应开放未经授权的“网页触发服务器安装”接口。**安装脚本支持管理员使用 `--three-tgz` 和 `--ocean-zip` 引入预先下载的官方归档；不能保证部署环境可访问外网。

注意：检测通过不代表所有运行时外部资源可用；遇到不稳定网络时，推荐直接访问服务器本地入口。Open Water 和 Three.js 可能对浏览器及 WebGL2 有要求。

## 文件说明
- `index.html`：自动检测、选择在线或服务器本地入口。
- `index-online.html`：使用在线依赖。
- `index-local.html`：只使用服务器已安装的 `vendor/` 依赖。
- `serve.py`：启动 HTTP 服务，`--install` 可选部署前安装。
- `install_dependencies.py`：服务器执行的单次依赖安装。
- `assets/`、`ships/`：GLB 模型、飞机和敌我战舰 JSON 数据。
