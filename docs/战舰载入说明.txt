《战舰，最后的防线》V13 战舰载入

1. 解压完整资源包，保持 assets 和 ships 目录结构。
2. 用 python -m http.server 8000 运行，并在浏览器访问 http://localhost:8000/ 。需要联网加载原有三维依赖。
3. 在开始界面「出击前舰艇配置」点击「导入我方 JSON / 模型」。可以一次选中 JSON 与 GLB 或 glTF ZIP，也可只导入 JSON 或模型。
4. JSON 包含舰体耐久、速度、炮塔炮位、主副炮、防空、技能，schemaVersion 必须为 1。模型与 JSON 一起提交时，仅在两者均校验成功后替换当前预览。
5. 下方可分别选择敌军巡逻艇、驱逐舰、巡洋舰、精英巡洋舰、战列舰、Boss 配置；选中舰种后导入对应 JSON，可附带模型。
6. 暂停后可点击「返回开始菜单」重新调整配置，已导入内容在当前页面内保留；刷新网页后浏览器本地上传的模型不自动保存，需要再次选择文件。
7. 自定义通用模型的炮位坐标由 JSON 指定。若模型没有对应炮塔节点，炮弹发射仍能工作，但模型实体炮塔可能不会旋转。
8. JSON 若引用其它外部贴图，建议将 glTF 及贴图打包 ZIP 一次导入。

注意：这份 V13 基于 V12 修复，图形引擎/Three.js 依赖外部网络，保持此前许可。
