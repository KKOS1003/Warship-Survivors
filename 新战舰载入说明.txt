战舰，最后的防线 V14
======================

本版修改：
1. BOSS 标记跟踪真实三维舰体顶部，仅在视野内悬浮于其上方；出屏时自动隐藏，不再出现边缘箭头。
2. 修复自由相机鼠标拖动的水平和垂直方向。
3. 增加马洛亚罗斯拉韦茨战舰 JSON 与独立 GLB 模型。

启动游戏：
  在当前目录运行： python -m http.server 8000
  浏览器打开： http://localhost:8000/
  浏览器需要联网获取 Three.js 与 Open Water。

新舰直接载入：
  开始界面 → 出击前舰艇配置 → ★ 载入新舰。
  或者点击“导入我方 JSON / 模型”，一次选择：
    ships/maloyaroslavets.json
    assets/soviet_hybrid_warship_maloyaroslavets.glb
  完成后查看预览，再开始战斗。

新舰数值：
  舰体耐久 810 · 最高航速 32 kn · 2座双管主炮 · 10门副炮 · 增强防空。
  Q 高速巡航：持续12秒，最大航速×1.40、加速×1.70、转舵×1.55，冷却45秒，消耗4补给。
  R 持续维修：总计160 HP/12秒，冷却1秒，消耗7补给，可叠加。
  T 主炮高速装填：持续11秒，主炮装填时间×0.56、单发伤害×1.28，冷却52秒，消耗6补给。

坐标说明：
  根据上传 GLB 主要406mm炮节点估算前甲板两座炮的射击坐标；副炮挂点为游戏化推定值。
  目前“generic”模型在游戏中使用逻辑炮塔，不自动旋转导入模型里的实体炮塔。
  如出现模型朝向、吃水或发射点偏移，可调整 JSON 的 model.yawOffsetDegrees、draftOffset、炮塔 origin 及 secondary.mounts。
  提供的强度为游戏平衡默认值，不是舰船真实历史技术数据。

单文件版：
  内置旧模型以控制文件体积，不内嵌31MB新舰GLB；如使用单文件版，请从文件对话框同时选择 JSON 和 GLB。

注意：
  本版做了脚本语法与资源文件结构校验，仍需在支持 WebGL 的浏览器中检验三维模型实际画面。
