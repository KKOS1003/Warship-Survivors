【新增：手动主炮瞄准镜】
Shift：切换开启/退出舰炮第一视角（按一次开启，再按一次退出，非长按）。
镜内右键按住拖动：调整水平、俯仰瞄准方向（上下拖动方向修复）；滚轮：放大/缩小。
进入炮瞄时保留当前镜头朝向，隐藏普通鼠标指针，使用光学准星瞄准。
镜内鼠标左键单击：按炮塔编号轮流发射一座已经转向、瞄准并装填就绪的炮塔。
镜内鼠标左键双击：发射所有已就绪炮塔进行齐射（不绕过装填或射界）。
双击检测需判断第二次点击；单击约 285ms 后执行，以免首击提前发射。
炮瞄时只有主炮自动射击暂时停用，副炮与防空仍自动工作；退出时恢复之前的自动火控设置。
炮弹遵循当前舰艇的炮位、单发伤害、散布、初速、重力和实体碰撞规则。
准星表示当前观察点/水面落点；不会自动预测敌舰速度，手动射击移动目标需要提前量。
刻度随视场和窗口变化，标准视场约 7 毫弧度/小格；横向、纵向刻度更长。
暂停、升级、返回开始菜单会退出瞄准镜。进入前为自由相机时，退出恢复原自由相机位置。

【键位调整】
左键海面：设置航点；Ctrl + 左键：追加航点（原 Shift+左键与炮瞄冲突，已更改）。
自由相机：WASD 移动；- /= 下降/上升；Alt + WASD 加速（原 Shift 加速已让给炮瞄）。
跟随模式：WASD 航行，右键拖动观察，滚轮缩放；B 切镜头；V 集火；C 取消集火。
技能：Q/R/T/E、P 暂停，主炮手动外可使用原来的主炮按钮/空格齐射。

《战舰，最后的防线 V12》

启动：解压资源包，进入目录运行 python -m http.server 8000，然后访问 http://localhost:8000/ 。首次打开需联网载入 Three.js 和 Open Water。

战舰选择：开始菜单 → 设置 → 战舰库；导入战舰 JSON + GLB/ZIP 模型。

敌舰配置：开始菜单 → 设置 → 敌军舰艇库；从下拉框选择 巡逻艇/驱逐舰/巡洋舰/精英巡洋舰/战列舰/BOSS，然后导入该类型 JSON，可同时附带独立 GLB/ZIP 模型。也支持导出、恢复默认。可以战斗中导入：已经生成的敌舰保留旧属性，接下来出现的该类敌舰使用新配置。

ships/enemies/ 下有六种可单独编辑的实例文件。敌我 JSON 共享 schemaVersion: 1，包含 model/stats/weapons/skills，敌方另外有 enemy 扩展块（生成航速、转向率、装填随机误差、奖励等）。

小艇一座主炮一根炮管，战列舰和 BOSS 由 turrets[].barrels 逐炮管射击；每座炮塔都有独立指向、转速、射界和装填倒计时。副炮每个挂点独立开火，防空只攻击阵营相对的飞机。敌军防空会攻击玩家的友军飞机；如场上无友军飞机则不浪费弹药。

BOSS 标记只固定显示在视野内的旗舰顶部；BOSS 不在画面内时不显示指向箭头。雷达上仍有 Boss 标记。

限制：自定义战舰模型的 pivotNode 需要和模型节点匹配；并非自动识别炮塔。敌军默认建模为用户提供的模型或程序化船体。运行依赖浏览器 WebGL 和联网 CDN。

V17 改动：
- 开始界面在左侧菜单之外的海面上按住鼠标左键拖动，即可绕舰展示；滚轮缩放预览。
- 取消页面拖拽导入；仍可通过开始界面的“导入我方 JSON / 模型”按钮载入。
- 默认在 HP ≤ 35% 且补给足够、技能未冷却时自动使用 R 持续维修。设置中可关闭/调整阈值；已有维修层时避免过度使用。
- BOSS 顶部标记使用实时三维舰体位置；Boss 离开视野后不再显示屏幕边缘箭头。


V20 新增炮瞄操作：Shift 进入/退出炮瞄；浏览器允许时自动锁定指针；无需按右键，鼠标移动即瞄准。
左键单击逐炮发射、双击就绪齐射，伤害×2；命中核心区、弹药库可触发额外倍率和勋章。
模型弱点坐标可编辑 ships/enemies/*.json 中的 model.criticalZones。
