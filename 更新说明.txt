《战舰，最后的防线》V20 更新说明

1. Shift 光学炮瞄：鼠标移动即可转动准星与瞄准视角，不必按住右键。
   进入炮瞄时请求浏览器鼠标指针锁定（Pointer Lock），避免移动到屏幕边缘时无法继续瞄准。
   如果浏览器阻止指针锁定，仍支持未锁定的鼠标移动作为备用输入。按 Shift 退出炮瞄会释放指针锁定。
   左键单击按炮塔顺序发射，左键双击发射所有就绪主炮；滚轮调整镜头缩放。
   原自动主炮在炮瞄期间暂停，炮塔转向、射界、装填与弹道规则继续生效。

2. 炮瞄主炮伤害 ×2：效果仅附加于炮瞄中生成的主炮弹，而不是命中瞬间的玩家模式。
   因而切出炮瞄后，已经在空中飞行的手动炮弹仍具有 ×2 的伤害属性。
   可继续受到主炮强化等已有技能加成和敌舰装甲减伤影响。

3. 新增敌舰弱点区域：
   核心区（citadel）：舰体中部较低的装甲核心，炮瞄弹命中伤害 ×4.5（叠加上面的 ×2）。
   弹药库（magazine）：前后主炮座下方，炮瞄弹命中伤害 ×7（叠加上面的 ×2）。
   只在炮弹真实碰撞位置位于区域内、且斜击角度不超过 68° 时触发；普通自动炮击不会触发。
   以上数值先计算装甲偏斜，再计算弱点暴击，敌舰装甲仍继续减伤。
   以上属于娱乐化舰体区域模型，不是对真实舰体装甲与弹药库的逐三角形穿透模拟。

4. 左上角荣誉勋章：本局记录核心区命中、弹药库命中、精准炮手（每 5 次核心区命中）
   以及致命打击（单发实际造成至少 250 伤害）。开新局清零。
   核心区、弹药库位置由 JSON model.criticalZones 配置，可按舰种分别编辑；未配置时自动推导。

模型、JSON 文件继续独立保存在 assets/ 与 ships/ 下，index.html 不嵌入任何 GLB/ZIP 模型数据。
启动方式：在本目录下执行 python -m http.server 8000，然后浏览器打开 http://localhost:8000/
需联网获取 Three.js 和 Open Water 的 CDN 依赖。

《战舰，最后的防线》V18 更新说明

《战舰，最后的防线》V18 操作说明

运行：将 ZIP 完整解压；在含有 index.html 的文件夹中运行：
  python -m http.server 8000
在浏览器打开 http://localhost:8000/
需要联网获取 Three.js、Open Water 引擎。GLB/ZIP 和 JSON 均已分离存放。

【新增：手动主炮瞄准镜】
Shift：切换开启/退出舰炮第一视角（按一次开启，再按一次退出，非长按）。
镜内右键按住拖动：调整水平、俯仰瞄准方向；滚轮：放大/缩小。
镜内鼠标左键单击：按炮塔编号轮流发射一座已经转向、瞄准并装填就绪的炮塔。
镜内鼠标左键双击：发射所有已就绪炮塔进行齐射（不绕过装填或射界）。
双击检测需判断第二次点击；单击约 285ms 后执行，以免首击提前发射。
炮瞄时只有主炮自动射击暂时停用，副炮与防空仍自动工作；退出时恢复之前的自动火控设置。
炮弹遵循当前舰艇的炮位、单发伤害、散布、初速、重力和实体碰撞规则。
准星表示当前观察点/水面落点；不会自动预测敌舰速度，手动射击移动目标需要提前量。
刻度按 5 毫弧度一格随视场角变化；显示测距、视场角、生存倒计时和各炮塔状态。
暂停、升级、返回开始菜单会退出瞄准镜。进入前为自由相机时，退出恢复原自由相机位置。

【键位调整】
左键海面：设置航点；Ctrl + 左键：追加航点（原 Shift+左键与炮瞄冲突，已更改）。
自由相机：WASD 移动；- /= 下降/上升；Alt + WASD 加速（原 Shift 加速已让给炮瞄）。
跟随模式：WASD 航行，右键拖动观察，滚轮缩放；B 切镜头；V 集火；C 取消集火。
技能：Q/R/T/E、P 暂停，主炮手动外可使用原来的主炮按钮/空格齐射。

【说明】
V18 在 V17 的资源分离工程上修改，不将 GLB/ZIP 模型内嵌回 HTML。
通过静态 UI、脚本语法和主炮逐炮/齐射条件测试；当前测试容器的本地 HTTP 页面被拦截，尚未完成三维渲染与完整 20 分钟战斗实机验证。

V16 更新摘要与历史记录
《战舰，最后的防线》V16 更新说明

【运行】
1. 解压完整资源包，保持 index.html、assets/、ships/ 的相对位置不变。
2. 在解压目录运行 python -m http.server 8000。
3. 用 Chrome / Edge 打开 http://localhost:8000/，需要联网加载 Three.js 和 Open Water 海面引擎。
4. 开始界面可选大和号或导入其他 JSON+GLB 模型。

【本次更新】
1. 默认大和号的基础战场物资吸附半径 115→250 米，新苏联战舰 122→260 米；经验球吸附半径是普通拾取范围的 1.45 倍：默认大和号约 363 米、新舰约 377 米。吸附速度提高，接近后自动拾取。
2. 场景指针改为高对比度白金色箭头；集火选中时为带黑色描边的金色准星。图标在 assets/ui_cursor.svg 和 assets/target_cursor.svg。
3. 大和号 E「主炮强化」：62 秒冷却；持续 14 秒；主炮伤害 ×1.35、弹道散布 ×0.72、炮塔转速 ×1.25，实际影响每发炮弹伤害、炮塔瞄准过程和主炮 UI。
4. Q / E 技能均不消耗补给，包括从自定义 JSON 导入的战舰；R 持续维修与 T 战术增压仍按战舰 JSON 指定消耗补给。
5. 前 3 分钟缓和难度：初始编队 5→3 艘，开局增援每约 24–33 秒（3 分钟后恢复约 15.5–23.5 秒），常规空袭间隔由 8.6 秒缓慢回到 6.2 秒。敌舰早期伤害减少、装填时间延长，效果随时间平滑递减，3 分钟后消失。
6. 新增敌军配置项：enemy.openingDamageMultiplier、enemy.openingReloadMultiplier，在前 180 秒与正常值之间线性过渡；可通过敌舰 JSON 逐舰种调整。

【数据文件】
ships/yamato.json：默认大和号，E 为主炮强化。
ships/maloyaroslavets.json：马洛亚罗斯拉韦茨，Q 高速巡航、E 轰炸机小队。
ships/enemies/*.json：敌军各舰种独立数据。

【说明】
· 内置 JSON 和 ships/ 中的示例数据保持一致；通过游戏导入的自定义战舰 JSON 也会使 Q/E 技能不消耗补给。
· 当前游戏仍从 CDN 请求三维渲染依赖，资源包并非完全离线版。
